# Visual asset attribution

## Driver avatar pack

The SVG files in `assets/drivers/` are original, programmatic fallback avatars created for this project. They are abstract initials graphics, not photographs, portraits, team logos, or likenesses of any driver.

- **Source:** created locally for the F1 Budget Allocator project.
- **Licence:** project-created artwork; no third-party image asset is embedded.
- **Use:** display a consistent driver identifier when no licensed headshot is available.

The team colour pairings are approximate UI palette references only. Formula 1, constructor names, driver names, and official team marks remain the property of their respective owners. This project does not include official F1 or constructor logos.

## Palette data

`assets/team_palettes.json` records accessible primary, secondary, and text colours for user-interface theming. It is an original application data file, not an official brand style guide.
