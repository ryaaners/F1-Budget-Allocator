# Driver portrait assets

The SVG files in this folder are original, programmatic fallback portrait badges made
for this local project. They are not photographs and do not use Formula 1, team, or
photographer-owned imagery. Each badge is identified by driver initials and can be
replaced with a locally licensed headshot at the same file path.

- **Source:** original vector artwork authored in this repository.
- **Third-party licence:** none; these files do not contain third-party imagery.
- **Replacement rule:** a future photo must include its source URL and licence in this
  file before it replaces a badge.
